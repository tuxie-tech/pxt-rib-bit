## Enum `SerialBaud`

Serial speeds the Rib:bit controller can use on the MikroBUS port. The values must match the baud table in the Rib:bit firmware.

- `BAUD_300 = 0x00`
- `BAUD_600 = 0x01`
- `BAUD_1200 = 0x02`
- `BAUD_2400 = 0x03`
- `BAUD_4800 = 0x04`
- `BAUD_9600 = 0x05`
- `BAUD_14400 = 0x06`
- `BAUD_19200 = 0x07`
- `BAUD_28800 = 0x08`
- `BAUD_38400 = 0x09`
- `BAUD_57600 = 0x0a`
- `BAUD_115200 = 0x0b`
- `BAUD_230400 = 0x0c`
- `BAUD_460800 = 0x0d`
- `BAUD_921600 = 0x0e`
